# Website Portofolio & Kumpulan Tugas Sekolah
## Abrielle Kayla Budiman — Sekolah Cinta Kasih Tzu Chi

Selamat datang di website portofolio digital **Abrielle Kayla Budiman** dari **Sekolah Cinta Kasih Tzu Chi**. Website ini dibuat menggunakan HTML, CSS (Tailwind CSS), dan JavaScript murni yang siap di-hosting di platform pilihan Anda.

---

## 🌟 Fitur Utama Website

1. **Desain Menarik & Responsive**:
   - Tema warna Biru Terang (Bright Light Blue & White) yang segar, bersih, dan modern.
   - Menggunakan Tailwind CSS CDN & FontAwesome 6 untuk tampilan interaktif & user friendly.
   - Tampilan sempurna di laptop, tablet, maupun HP (Mobile Responsive).

2. **Menu Navigasi Lengkap**:
   - **Dashboard**: Halaman utama dengan ringkasan profil, ucapan selamat datang, statistik tugas, kata perenungan Jing Si Tzu Chi, dan cuplikan karya terbaru.
   - **Profil**: Informasi diri Abrielle, asal sekolah (Sekolah Cinta Kasih Tzu Chi), keahlian, budaya humanis Tzu Chi, serta link sosial media.
   - **Informatika**: Kumpulan tugas mata pelajaran Informatika (Pemrograman Web, Algoritma, Computational Thinking, Literasi Digital).
   - **Bahasa Indonesia**: Kumpulan tugas & karya mata pelajaran Bahasa Indonesia (Laporan Hasil Observasi, Puisi, Resensi Buku, Esai).

3. **Fitur Ubah Foto Profil Live (Disimpan di Browser)**:
   - Abrielle dapat mengubah foto profil di Dashboard dan Profil kapan saja langsung dari tombol "Ganti Foto".
   - Foto otomatis tersimpan di memori browser (`localStorage`).

4. **Fitur Tambah Tugas & Filter Interaktif**:
   - Abrielle dapat menambahkan tugas baru untuk Informatika maupun Bahasa Indonesia langsung lewat form modal di website.
   - Terdapat tombol filter kategori dan pop-up modal detail untuk membaca tugas.

5. **Link Sosial Media**:
   - Terintegrasi langsung dengan link **Instagram** dan **TikTok** di navbar header, widget profil, dan footer.

## 🌐 Cara Hosting Website (Menjadikan Website Online)

Anda dapat mengunggah file ini ke web hosting gratis maupun berbayar agar bisa diakses oleh siapa saja lewat internet:

### Pilihan 1: Netlify (Sangat Mudah & Gratis)
1. Buka [netlify.com](https://www.netlify.com) dan buat akun (bisa login lewat Google / GitHub).
2. Di halaman Dashboard Netlify, drag & drop folder `informatika Abrielle` ke area **Sites**.
3. Website Abrielle langsung online dalam hitungan detik dan akan mendapatkan link URL gratis!

### Pilihan 2: Vercel (Gratis & Cepat)
1. Buka [vercel.com](https://vercel.com).
2. Pilih **Add New Project** -> **Deploy from local folder** / Upload zip.
3. Klik **Deploy**.

### Pilihan 3: GitHub Pages (Gratis & Profesional)
1. Buat repository baru di GitHub dengan nama `abrielle-portfolio`.
2. Upload file `index.html` dan folder `assets/`.
3. Masuk ke **Settings** -> **Pages** -> Pilih branch `main` -> Klik **Save**.
4. Website akan aktif di `https://username.github.io/abrielle-portfolio`.

### Pilihan 4: Web Hosting Biasa (cPanel / Hostinger / Niagahoster)
1. Masuk ke cPanel atau File Manager hosting Anda.
2. Buka folder `public_html`.
3. Upload file `index.html` beserta folder `assets/`.
